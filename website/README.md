# Everpeace Companionship — public website

Static, bilingual site generated from the Everpeace Companionship website design (Claude Design canvas).

- `index.html` — English · `fr.html` — French
- `images/` — logos, partner logos, QR codes, intro image
- The visit counter reads `../visit-total.json` (same number as the coordinator dashboard).

Do not edit these files by hand: change the design, then regenerate the site.
